# WATERS 舆情引擎

在任意国家采集消费者对台式饮水机、净水器和滤水壶的公开讨论，按 WATERS 需求框架和情感对每条观点进行分类，
并生成 Excel 报表。

网页界面支持中文和英文（在左侧栏顶部切换）。English: [README.md](README.md).

---

## 快速开始

需要 Python 3.9 或更高版本。

```bash
python3 -m venv .venv
source .venv/bin/activate            # Windows：.venv\Scripts\activate
pip install -r requirements.txt
python -m src.cli web                # 打开 http://localhost:8501
```

使用网页时请保持终端窗口开着；按 `Ctrl+C` 停止。

### 首次设置（「⚙ 设置」页）

| 设置项 | 说明 |
|---|---|
| **机构名称 + 联系邮箱** | 工具访问的每个网站都会看到是谁在采集、如何联系。必填。 |
| **AI 服务商 + API 密钥** | 用于给帖子分类，并协助设置国家和网站。可选择 Claude、通义千问、DeepSeek、智谱 GLM、豆包或任何兼容 OpenAI 格式的接口。填好后点击 **测试连接**（设置会自动保存）。 |
| **YouTube Data API v3 密钥** | 默认数据来源。Google Cloud 控制台 → 启用 *YouTube Data API v3* → 凭据。点击 **测试 YouTube**。 |
| **作者加密盐** | 点击 **生成**。用户名在保存前会用它加密。生成后请勿更改。 |

所有设置保存在本机的 `.env` 文件中。该文件含有密钥，请勿分享或上传。

### 运行一个国家

1. **左侧栏**：选择国家，或 **添加国家** → **用 AI 起草**（或 **从空白开始**）。
2. **1 · 国家设置**：检查语言、搜索词和品牌清单，修改会自动保存。AI 起草的内容只是起点，采集前请核对品牌。
3. **2 · 数据来源**：默认开启 YouTube。可选：粘贴论坛/评测页面地址、自定义 API、Reddit 凭据，或上传人工收集的 CSV。
4. **3 · 运行**：点击 **一键全部运行**（采集 → 分类 → 导出）。「分类」会先对新的 YouTube 视频做市场检查。在后台运行，日志实时更新。
5. **4 · 结果**：图表、证据引用、**质量抽查**和报表下载。

## AI 服务商

- **请固定使用同一个模型。** 不同模型的结果不可比较。不同国家、不同时间请使用同一服务商和模型；更换后请重新抽查。
- 服务商支持严格 JSON 输出时会自动使用，否则自动改用普通 JSON 模式。无论哪个服务商，每条分类都必须逐字引用原帖，
  原帖中找不到的引用会被丢弃。
- **请确认使用资格。** Anthropic（Claude）不在中国大陆提供服务，并限制由不受支持地区控制的公司使用。
  请与法务部门确认贵公司可以使用哪些服务商。

## 在中国大陆运行

- **YouTube 在中国大陆无法访问。** 请在具备合规国际网络的环境（如海外办公室）中运行采集。
- **国内平台**（小红书、抖音、知乎、京东、天猫）没有开放 API，且有严格的反爬机制。本工具不会采集这些平台，
  电商网址会被直接拒绝。请通过 **自定义 API** 接入有授权的数据服务商，或使用 CSV 上传。
- **跨境数据。** 将采集的帖子跨境传输或发送给 AI 服务商，可能需要按照《个人信息保护法》及来源国法律进行审批，
  即使用户名已经加密。

## 市场检查（YouTube）

YouTube 搜索不区分市场：为新加坡搜索，也会搜到美国的滤水壶测评、印度的 RO 科普视频。分类之前，
AI 会根据每个新视频的标题、频道、简介和部分评论做出判断：

| 判断 | 是否计入分析 |
|---|---|
| 目标市场：内容关于本国，或评论者来自本国 | 是 |
| 其他市场：面向其他国家（会记录是哪个国家） | 否 |
| 全球通用、无国家信号：如通用科普视频 | 否；在「数据来源」页开启 **同时保留看不出属于哪个国家的视频** 后为是 |
| 品类不符：空气净化器、鱼缸、工业过滤器等 | 否 |
| 无关内容 | 否 |

- 自动运行，无需人工操作。每个视频只判断一次，新视频在下次「分类」时判断。
  `python -m src.cli --country sg scope --recheck` 可重新判断所有视频。
- 不删除任何数据。被排除的评论仍保留在数据库中，并列在 `Raw_Documents.csv` 里。报表的 **Market_Check**
  表列出每个视频的判断和理由，README 表统计排除数量。
- 被排除的视频不会进入分类，不产生分类费用。视频被排除前已分类的评论会保留，但不再计入分析。
- 使用「设置」中的辅助模型。使用 Claude 时为 Opus；每 10 个视频调用一次。
- 只检查 YouTube：网站、API、Reddit 和 CSV 都是人工选择的来源。

## 质量抽查

在 **结果** 页点击 **随机抽查 20 条**。工具会逐条显示 AI 给出的需求和情感，您点击 ✓ 正确 或 ✗ 错误。
正确率会显示在结果页，并写入报表的 README 表。每个国家建议至少抽查 20 条；正确率低于约 80% 时，
请谨慎使用相关数据，可考虑更换模型或完善品牌和搜索词设置。

抽查时可以看到 AI 的答案，因此它衡量的是「分类经人工复核是否站得住」，而不是独立的第二次编码。

## WATERS 需求

| 代码 | 名称 | 含义 |
|---|---|---|
| W | 健康安全 | 保护使用者或家人的健康安全（儿童、老人、婴儿冲奶、防烫） |
| A | 即取即用 | 速度、随取随用、免等待、容量 |
| T | 口感品质 | 味道、气味、温度精准度、冲咖啡泡茶 |
| E | 空间安装 | 尺寸、台面空间、安装、接水管 |
| R | 信赖保障 | 卫生（发霉、水箱）、滤芯、售后、保修、品牌信誉 |
| S | 社交形象 | 待客、外观、品味表达 |
| COST | 成本 | 价格、性价比、滤芯费用 |
| OTHER | 其他 | 相关但不属于以上任何一类 |

## 伦理与数据

- 遵守每个网站的 robots.txt（包括 Crawl-delay），遇到 403、429 或禁止访问立即停止。
- 同一网站的请求间隔至少 2 秒，出错时自动退避。
- 绝不绕过反爬措施：不破解验证码，不登录。
- 电商页面（Shopee、Lazada、亚马逊、淘宝、天猫、京东等）一律拒绝。
- 用户名在入库时加盐哈希，从不保存原始用户名。
- API 密钥只保存在本机 `.env` 中，不会写入国家配置。
- 读取粘贴的网站时，会把该页面的结构概要（含公开显示的昵称）发送给 AI 服务商，每个网站一次。
